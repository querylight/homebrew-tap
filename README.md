# QueryLight Homebrew tap

```sh
brew install --cask querylight/tap/querylight
```

| Cask | App |
|---|---|
| `querylight` | [QueryLight](https://querylight.app), a SQLite IDE for macOS 14+ |

QueryLight updates itself through Sparkle, so `brew upgrade` leaves it alone unless you add `--greedy`. `brew uninstall --zap --cask querylight` also removes its settings and caches.
